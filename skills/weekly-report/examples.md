# 周报示例

## 默认模板（推荐）

```markdown
# 周报

**周期**：本周（或用户指定日期）
**主要方向**：一句话概括本周主线

---

## 一、本周工作概述

2–4 句概括：做了哪些项目、重点成果、是否含联调/自查/设计开发。

---

## 二、[项目A名称]

### 2.1 [子模块 / 方向]

| 类别 | 工作内容 |
|------|----------|
| 业务逻辑 | … |
| 配置与规范 | … |
| 质量保障 | … |

或 bullet 列表（条目较少时）。

### 2.2 [子模块B]

- 事项 1（合并后的表述）
- 事项 2

---

## 三、[项目B名称]

| 阶段 | 工作内容 |
|------|----------|
| 调研与设计 | … |
| 开发实现 | … |
| 测试 | … |

---

## 四、培训与其他

- …

---

## 五、本周产出小结（可选）

1. …
2. …

---

## 六、下周计划（可选，用户需要时）

- [ ] …
```

## 三栏模板（用户明确要求时）

```markdown
# 周报

**周期**：…

## 本周完成

- [项目] …

## 遇到的问题

- （无则写「无」或省略）

## 下周计划

- [ ] …
```

## 输入 → 输出片段示例

**输入（日报片段）**：
```
征服3职业系统 - 州府战状态判断优化
征服3职业系统 - 自查修复代码逻辑NPE
【征服3职业系统】【工匠】挖掘 - 新增skillLevel字段
【官渡之战】【匹配】按赛季拆分匹配数据
公司培训 - 第57期途游新手村培训
```

**输出（合并后片段）**：

```markdown
## 二、征服3职业系统

### 2.1 通用 / 服务端基础
- 州府战状态判断优化
- 质量保障：自查修复 NPE

### 2.2 【工匠】挖掘
- 新增 skillLevel 字段

## 三、官渡之战 · 匹配
- 按赛季拆分传入数据与匹配结果，单赛季失败不影响其他赛季

## 四、培训与其他
- 第 57 期途游新手村培训
```
